# Prompts de avatares CyberGuard

Estos prompts se incluyen para documentar una futura generación de retratos coherentes. En la implementación actual se reutilizan [professor_byte.png](assets/portraits/professor_byte.png) y [nullsec.png](assets/portraits/nullsec.png), que ya formaban parte del proyecto; no se afirma que hayan sido generados durante esta sesión.

## Auditor

```text
Ilustración vectorial 2D cyberpunk de una auditora y desarrolladora de ciberseguridad llamada Byte, vestuario tecnológico funcional en tonos grafito, azul eléctrico y verde cibernético, iluminación lateral azul y verde, expresión inteligente, paciente y confiable, mirada dirigida al estudiante, silueta clara para un avatar de interfaz, fondo transparente, alto contraste, formas limpias, sin texto, sin logotipos, estilo coherente para un dashboard educativo profesional.
```

## Atacante simulado

```text
Ilustración vectorial 2D cyberpunk de un atacante ficticio llamado NullSec, capucha oscura y vestuario técnico, iluminación roja y morada, apariencia misteriosa pero no glorificada, expresión de advertencia, silueta clara para un avatar de interfaz, fondo transparente, alto contraste, formas limpias, sin texto, sin logotipos, mismo lenguaje visual y proporción que el avatar de la auditora, uso educativo para representar una amenaza simulada.
```

## Reglas de uso

Los avatares deben funcionar a 86×86 px dentro del panel de diálogo, conservar lectura facial y no incluir marcas reales, credenciales, datos personales ni instrucciones operativas de ataque.
